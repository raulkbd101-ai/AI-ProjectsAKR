Governed Agentic BI

A small, runnable reference demo for routing analytics requests through an allowlisted tool with server-side role scopes and an audit trail.

Role selection is a demo control, not identity verification. The app enforces the selected policy on the server to demonstrate the pattern.

Prototype boundary: This demo uses invented data and deterministic intent routing. It does not call an LLM, authenticate users, or represent a production security control.
